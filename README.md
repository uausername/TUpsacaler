# Telegram Photo Upscaler Bot

Простой Telegram бот для увеличения разрешения фотографий с помощью улучшенных алгоритмов масштабирования.

## Возможности

- 📸 Увеличение разрешения фотографий в 2 раза
- 🎨 Улучшение качества изображения (резкость, контраст, насыщенность)
- ⚡ Быстрая обработка с использованием оптимизированных алгоритмов
- 🔄 Автоматическое определение и конвертация форматов
- 📱 Удобный интерфейс через Telegram

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd telegram-photo-upscaler-bot
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
source venv/bin/activate  # На Linux/Mac
# или
venv\Scripts\activate  # На Windows
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка бота

1. Создайте бота через [@BotFather](https://t.me/BotFather) в Telegram
2. Скопируйте `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```
3. Откройте `.env` и вставьте токен вашего бота:
   ```
   TELEGRAM_BOT_TOKEN=your_bot_token_here
   ```

### 5. Запуск бота

```bash
python bot.py
```

## Использование

1. Найдите вашего бота в Telegram
2. Отправьте команду `/start` для начала работы
3. Отправьте фотографию для апскейлинга
4. Дождитесь обработки (обычно 10-30 секунд)
5. Получите улучшенную версию фотографии

### Команды бота

- `/start` - начать работу с ботом
- `/help` - показать справку
- `/status` - проверить статус бота

## Технические детали

### Алгоритм апскейлинга

Бот использует улучшенный алгоритм масштабирования:

1. **Предварительная обработка**: Ограничение размера для оптимизации
2. **Масштабирование**: LANCZOS алгоритм для высокого качества
3. **Постобработка**: 
   - Улучшение резкости (+20%)
   - Улучшение контраста (+10%)
   - Легкое улучшение насыщенности (+5%)

### Поддерживаемые форматы

- **Входные**: JPG, PNG, WEBP
- **Выходные**: JPG (высокое качество)

### Ограничения

- Максимальный размер файла: 20MB (ограничение Telegram)
- Максимальное разрешение для обработки: 1024px по большей стороне
- Коэффициент увеличения: 2x
