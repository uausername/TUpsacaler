# 📸 Telegram Photo Upscaler Bot

Telegram бот для автоматического улучшения качества изображений с использованием технологии Real-ESRGAN.

## 🌟 Возможности

- 📈 Увеличение разрешения изображений в 4 раза
- 🎨 Улучшение качества и детализации фотографий
- 🚀 Использование современной нейросети Real-ESRGAN
- 💯 Полностью бесплатная работа
- 🔒 Конфиденциальность: изображения не сохраняются

## 🛠️ Технологии

- Python 3.8+
- [python-telegram-bot](https://github.com/python-telegram-bot/python-telegram-bot) - для работы с Telegram API
- [Real-ESRGAN](https://github.com/ai-forever/Real-ESRGAN) - модель апскейлинга изображений
- PyTorch - фреймворк машинного обучения
- Pillow - обработка изображений

## 📋 Требования

- Python 3.8 или выше
- Токен Telegram бота (получить у [@BotFather](https://t.me/BotFather))
- 2+ ГБ оперативной памяти
- (Опционально) NVIDIA GPU с CUDA для ускорения обработки

## 🚀 Установка и запуск

### 1. Клонируйте репозиторий

```bash
git clone <repository-url>
cd TUpscaler
```

### 2. Создайте виртуальное окружение

```bash
python -m venv venv

# Linux/Mac
source venv/bin/activate

# Windows
venv\Scripts\activate
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

**Для GPU (CUDA):**
```bash
# Вместо обычного torch установите версию с CUDA
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118
```

### 4. Создайте Telegram бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и получите токен
4. Скопируйте токен

### 5. Настройте переменные окружения

```bash
# Скопируйте пример конфигурации
cp .env.example .env

# Откройте .env и вставьте ваш токен
nano .env
```

Замените `your_bot_token_here` на ваш токен от BotFather:
```
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
```

### 6. Запустите бота

```bash
python bot.py
```

Вы должны увидеть сообщение:
```
✅ Бот успешно запущен! Нажмите Ctrl+C для остановки.
```

## 📱 Использование

1. Найдите вашего бота в Telegram
2. Отправьте команду `/start`
3. Отправьте любое изображение
4. Дождитесь обработки (10-60 секунд)
5. Получите улучшенное изображение!

### Команды бота

- `/start` - Приветственное сообщение и инструкция
- `/help` - Справка по использованию

## ⚙️ Настройки и ограничения

### Текущие параметры:
- **Масштаб увеличения:** x4
- **Максимальный размер:** 2000x2000 пикселей
- **Поддерживаемые форматы:** JPG, PNG, WEBP
- **Выходной формат:** PNG

### Изменение параметров:

В файле `bot.py` вы можете изменить:

```python
# Масштаб увеличения (2, 4, 8)
model = RealESRGAN(device, scale=4)

# Максимальный размер изображения
max_dimension = 2000

# Качество выходного изображения
upscaled_image.save(output_buffer, format='PNG', quality=95)
```

## 🐛 Решение проблем

### Бот не запускается
- Проверьте, что токен указан правильно в `.env`
- Убедитесь, что все зависимости установлены: `pip install -r requirements.txt`

### Ошибка "Out of memory"
- Уменьшите `max_dimension` в `bot.py`
- Закройте другие приложения для освобождения памяти
- Используйте изображения меньшего размера

### Медленная обработка
- Первая обработка может быть медленной (загрузка модели)
- Используйте GPU для ускорения (в 5-10 раз быстрее)
- Проверьте, что PyTorch использует GPU: добавьте в начало `bot.py`:
  ```python
  print(f"CUDA доступна: {torch.cuda.is_available()}")
  ```
